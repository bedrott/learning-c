# Chapter 01 - Introduction

## Origins of C
- Created in the early 1970s at Bell Labs by **Dennis Ritchie** and **Ken Thompson**.
- Evolved from **B** and **NB (New B)** to rewrite the UNIX kernel (originally written in PDP-7 Assembly).
- **Portability:** Writing UNIX in C allowed the OS to be ported to different hardware architectures simply by writing new C compilers.

## Key Strengths
- Low-level access to system memory and hardware.
- High performance and efficiency.
- Foundation for modern operating systems (Linux kernel, UNIX) and databases.
